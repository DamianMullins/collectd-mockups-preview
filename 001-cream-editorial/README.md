# Variant: Cream Editorial

## Design stance
Full Settee-language transplant: warm cream paper, rust accent, editorial serif
(Literata), tilted polaroid imagery — collectd as a cosy, magazine-grade brand.

## Key choices
- Layout: split hero (statement copy left, floating polaroid collage right),
  then long-form editorial feature rows rather than a card grid
- Typography: Literata serif display with italic rust accents + Inter UI
- Color: Settee's `#f6f1e7` cream / `#9a5b33` rust / `#24221c` ink
- Interaction: bobbing polaroids, hover-straighten, scrolling tag marquee,
  FAQ accordions, scroll-reveal
- Imagery: real Unsplash collector photos (vinyl, sneakers, figures, comics)

## Trade-offs
- Strong at: personality, warmth, differentiation from the current shadcn look
- Weak at: literal fidelity to the collectd green brand (rust replaces it);
  polaroid captions can sit under overlapping cards until hover

## Best for
- If Damian wants collectd to feel like a *place*, not an app — warm, tactile,
  editorial. Biggest identity change of the three.
